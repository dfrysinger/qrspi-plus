# F01: `## Cross-References` section is synthesized content absent from all q-file Summary blocks

## Description

`research/summary.md` lines 234–242 contain a `## Cross-References` section with six synthesized bullets drawing connections across question pairs (Q01↔Q02, Q08/Q15↔Q09, Q10↔Q08/Q15, Q11↔Q12, Q03↔Q04, Q05/Q13↔Q07).

This section does not appear in any individual q-file's `## Summary` block. All 12 q-files were checked (q01-codebase.md through q12-web.md): none contain a cross-reference sub-section within their `## Summary` block.

## Rule violated

> summary.md must be a verbatim extraction of the per-question `## Summary` blocks from the `q*.md` files; any paraphrasing, editorializing, or synthesis introduced during collation is a finding.

The `## Cross-References` section is new editorial synthesis generated by the collator — it is not a verbatim extraction of any source Summary block.

## Relationship to round-2 F01

The round-2 fix corrected the three bogus env var names within the Q08/Q15↔Q09 cross-reference bullet. That fix is accurate: the bullet now cites only `COPILOT_CLI=1` (q09-web.md v0.0.421) and `COPILOT_AGENT_SESSION_ID` (q09-web.md v1.0.29), both verified present in q09-web.md. The bullet-level fix is clean. However, the containing `## Cross-References` section — whose synthesized nature was not flagged in round-2 — violates the verbatim-collation rule regardless of the bullet-level accuracy.

## Evidence

- `research/summary.md` lines 234–242: `## Cross-References` section present.
- q01-codebase.md through q12-web.md `## Summary` blocks: none contain a cross-reference section or any analogous synthesis block. Verified by reading each q-file's `## Summary` section in full.

## Recommended fix

Remove the `## Cross-References` section entirely from summary.md. If cross-reference synthesis is desired for a research deliverable, it should live in a separate section explicitly chartered as synthesis (not in summary.md, which is specified as a verbatim collation artifact).
